# 🚀 Portfólio de Engenharia de Software — Anauã Maria

Repositório oficial do meu portfólio web interativo, desenvolvido para apresentar projetos Full-Stack, decisões de arquitetura de sistemas e competências técnicas.

🌐 **Acesse o portfólio ao vivo:** [https://anauaoliveira.github.io](https://anauaoliveira.github.io)

---

## ✨ Destaques da Interface & Engenharia

* **Hero Section & Background Interativo:** Canvas API com partículas conectadas, cubo wireframe 3D em CSS, aurora digital e cursor magnético.
* **Tech Stack & Arquitetura:** Faixa infinita dupla (marquee) interativa com modal explicativo e matriz expansível por camadas (Front-end, Back-end, Banco de Dados e Cloud/DevOps).
* **Cases de Produto (3D Tilt):** Apresentação interativa dos sistemas desenvolvidos com revelação de decisões técnicas e links diretos para os repositórios.
* **Terminal CLI Interativo:** Simulador de linha de comando (`ana@portfolio:~$`) com suporte aos comandos `help`, `whoami`, `about`, `skills`, `projects`, `contact`, `resume` e `clear`.
* **Timeline & Métricas:** Linha do tempo animada conforme a rolagem da página e painel de indicadores técnicos.

---

## 🛠️ Tecnologias Utilizadas

* **Estrutura & Estilo:** HTML5 Semântico, CSS3 (Grid Layout, Flexbox, Glassmorphism, Animações 3D)
* **Interatividade & Gráficos:** JavaScript (ES6+, Canvas API, DOM Manipulation)
* **Hospedagem & CI/CD:** GitHub Pages
